# TRAPFALL

A real-time multiplayer strategy game where players navigate a grid, make tactical moves, and avoid hidden traps.

### About

TRAPFALL is a multiplayer grid-based game built to explore real-time game architecture.

Players move across a finite board while the backend manages:
- player state
- game instances
- rooms
- real-time events



## Features

### Implemented

- JWT-based authentication
- WebSocket real-time communication
- Multiplayer room system
- Game instance management
- Player assignment
- Event-based message handling
- Basic player movement validation
